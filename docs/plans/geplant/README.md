# Geplante Pläne

bis der Owner sie in ein Vorhaben holt (siehe [`docs/STAND.md`](../../STAND.md)).

(erledigt oder gegenstandslos): hier liegt, was noch kommt. Ein Plan wandert
von hier nach `docs/plans/`, sobald ein Vorhaben ihn aufnimmt.
